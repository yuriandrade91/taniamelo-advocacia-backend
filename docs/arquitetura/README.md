## Atualizar um diagrama

Os links acima carregam o diagrama **codificado na própria URL**: editou o `.puml`,
o link antigo continua mostrando a versão anterior. Para atualizar, cole o conteúdo
do arquivo em <https://www.plantuml.com/plantuml/uml/>, renderize e troque os links
deste README pelos novos. No VS Code, a extensão PlantUML mostra o preview direto
do `.puml`, sem passar pelo servidor.

> O plantuml.com recebe o texto do diagrama (vai na URL). Só nomes de componentes e
> fluxos — nenhum segredo, IP ou dado de cliente entra nestes arquivos.
